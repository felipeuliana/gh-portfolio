# Portfolio

## goal
Create a personal portfolio developed with HTML, JS and Tailwind and published with Github pages.

## context
As a senior frontend developer plan, archtect and develop a portfolio single page to display web projects for external clients verification.

## scope
- Prioritize Responsive/Mobile first implementation:
  - mobile: < 480px
  - tablet: < 768px
  - desktop: < 1366px
- Use semantic HTML markup;
- Prioritize Accessibility (WCAG/AA);
- Follow JavaScript clean code;
- Target a performance between 90-100 score on lLighthouse;
- Do not add placeholder content - implement clean loading skeletons instead;
- Isolate content data in fixtures json files;
- Use the following color palette:
  - accent/AMBER_EARTH: '#e28413ff'
  - light/GHOST_WHITE: '#fffaffff'
  - neutral/SHADOW_GREY: '#1e1e24ff'
  - primary/BUBBLE_GUM_PINK: '#f45b69ff'
  - secondary/ROSY_GRANITE: '#7f7b82ff'
- Use the following font family:
  - Fira Sans
  - Fira Code
- Use the following type scale:
  - Minor third - 1.200
  - base size - 18px
- Design based on the portfolio website of Carlos Roriguez;
- References:
