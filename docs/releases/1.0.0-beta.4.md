# Portfolio 1.0.0-beta.4

_Released 2026-10-17_

This release introduces full bilingual support, allowing you to read the entire portfolio in English or Brazilian Portuguese with instant language switching and shareable links.

## Highlights

- **Bilingual portfolio content**: You can now switch between English and Brazilian Portuguese, with complete translations across profile details, showcase projects, skills, and contact forms.
- **Persistent language routing**: Your chosen language stays saved in your browser, and clean URL paths allow sharing direct links to localized versions.

## Improvements

- Accessible language selection menus are available in both desktop and mobile headers.
- Page metadata, title, and document language tags update dynamically when you switch languages.
- An automated translation validator runs during build time to ensure every required translation key exists.
- Screen reader accessibility labels and dynamic announcements speak in your selected language.

## Fixes

- Fixed duplicate accessibility module imports to ensure clean bundle composition.

## Upgrade notes

No action is required. Your browser language is detected automatically when you arrive, and you can switch languages anytime using the menu in the navigation bar.
