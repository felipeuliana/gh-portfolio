# Portfolio 1.0.0-beta.2

_Released 2026-09-17_

This beta improves the mobile browsing experience and makes project previews load correctly in the published GitHub Pages site.

## Highlights

- **Reliable project previews**: Project images now resolve correctly in the production site, including GitHub Pages deployments.
- **Improved mobile navigation**: The mobile menu now fills the viewport with a solid dark surface and keeps the page from scrolling behind it while it is open.

## Improvements

- The mobile navigation drawer now maintains a consistent layout during opening and closing.
- The navigation overlay uses a dedicated stacking context so page content does not show through the menu.

## Fixes

- Fixed a problem where project thumbnails could fail to load after deployment.
- Fixed a problem where the mobile navigation menu could show the page content behind it or allow the underlying page to scroll.

## Upgrade notes

No action is required. Use the published beta release or rebuild the project with the existing `pnpm install` and `pnpm build` commands.
